# Daily Publish Checklist v0.1

Use this checklist for each operating day of the `30`-day PR Activity launch.

## Pre-Publish

- confirm meditation session captured
- confirm yoga session captured
- confirm files are named with date, practice type, duration, and day number
- confirm masked identity boundary is preserved
- confirm no outcome guarantee appears in title, thumbnail, or description

## YouTube Primary Publish

- upload meditation full session
- upload yoga full session
- add each video to the correct playlist
- use the same title stem for both videos
- save both YouTube URLs into the launch log

## Support Posts

- publish Instagram support post only if it can be completed without custom editing backlog
- publish Facebook support post using the same source material
- publish LinkedIn only on planned weekly discipline posts
- cap total support-post work at `60` minutes median per day

## Daily Log

- record publish URLs
- record upload minutes
- record support-post minutes
- record missed steps
- record one next-day fix if friction appeared

## Hard Stops

- stop adding formats if YouTube publishing is not complete
- stop support posting if it causes same-day backlog
- stop any paid promotion until the `30`-day scorecard passes
